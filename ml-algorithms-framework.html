01 · The landscape

How the algorithms relate to each other

Two questions place any algorithm on this map. Down the side: does it learn from labeled examples, or find structure on its own? Across the top: is it classical ML, deep learning, or a model that creates new content? Moving right, models need more data and compute, and handle less structured inputs.

More data, more compute, less structured inputs, harder to explain

Self-supervised learning is a branch of unsupervised learning: the model hides part of its own input (the next word, a masked patch of an image) and learns to predict it, so no human labeling is needed. It is how large language models are pretrained.

04 · Putting it to work

Which algorithm to try first

A starting point, not a rule. In practice the right approach is to begin with a simple, explainable baseline, then move to a more complex model only when it measurably beats that baseline.

Rows and columns

Claims, members, transactions, a spreadsheet with a label to predict

  1. Logistic regression as the baseline
  2. Gradient boosting for accuracy
  3. Random forest as a robust alternative

Images or video

Scans, photos, inspection cameras

  1. A pretrained CNN, fine-tuned on your images
  2. A vision transformer for large datasets

Text

Notes, emails, tickets, documents

  1. Naive Bayes for a fast classifier baseline
  2. A fine-tuned or prompted transformer

Create something new

Draft text, generate images, synthesize test data

  1. Transformer (LLM) for text and code
  2. Diffusion for images
  3. GAN for synthetic records

No labels at all

Explore, segment, or simplify the data

  1. K-means to find natural groups
  2. PCA to reduce and visualize features

Sequences over time

Vitals, sensor feeds, demand history

  1. Gradient boosting on lag features
  2. LSTM for long, complex sequences
